# miniz-opt v0.1.0

Byte-identical drop-in replacement for [miniz](https://github.com/richgel999/miniz)
v3.1.2 (`77d0dce`) with added baseline SIMD and a slicing-by-8 CRC-32.

## What changed

Only new internal helpers and guarded kernel substitutions; the public headers
are declarations-compatible and the exported symbol set is exactly upstream
(115 symbols). The exact tier is **byte-identical** to the pristine oracle for
the compressed stream, the decompressed stream, and both checksums.

- `miniz_tdef.c`: SIMD match-length scan + the 16-bit unaligned probe filter;
  level 1 is held on the normal parser (`MINIZ_EXACT_LEVEL1`) so its bytes match.
- `miniz_simd.h` (new, internal): SSE2 match scan / inflate copy, SSSE3+SSE4.1
  adler32, slicing-by-8 crc32, self-contained CPUID/XGETBV.
- `miniz_opt.h` (new, internal): candidate build configuration.

## Results (clang 23.1.2, i7-14700F, WSL2; vs stock upstream `-O2`)

| workload | result |
|---|---|
| Compression (regime matrix, levels 1/6/9) | **+21%** geomean |
| Decompression | +1.7% (parity) |
| crc32 / adler32 (isolated) | **4.0× / 3.8×** |
| Downstream consumer (2 MiB text, zlib API) | **compress 1.32×**, decompress 1.04× |

Held-out PGO was measured and rejected (it regressed inflate); see
`docs/REJECTED.md`.

## Compatibility

- x86-64 baseline: **x86-64-v2** (SSE4.2/SSSE3), as the sibling stb forks.
  `MINIZ_NO_SIMD` gives a portable scalar build; `MINIZ_FORCE_BASE` omits AVX2.
- Verified byte-exact on clang/gcc, `-O2/-O3/-Os/-march=v2/v3/native`, C++, and
  cross-builds for aarch64-linux-musl, x86_64-linux-musl, x86_64-windows-gnu,
  aarch64-macos.
- 39-file differential × 11 levels × 5 strategies × {raw,zlib,single-shot,
  streaming}; ASan+UBSan clean; baseline `ymm`/`zmm` = 0.

## Artifacts

Static library plus the unchanged public headers, per target. Link the archive
and include the headers; header-only consumers get the baseline build.
