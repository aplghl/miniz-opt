# miniz-opt v0.1.0

**A byte-identical, drop-in performance fork of [miniz](https://github.com/richgel999/miniz) v3.1.2.**

`miniz` is a single-file zlib/DEFLATE replacement. Out of the box it is fully
scalar — `MINIZ_USE_UNALIGNED_LOADS_AND_STORES` defaults to `0` on every
platform and there is no SIMD at all. This fork adds baseline SIMD to the hot
codec and checksum paths while preserving the exact observable output contract:
the compressed stream, the decompressed stream, and both checksum values are
**bit-identical** to pristine upstream. It is a drop-in static library.

- **Upstream base:** `richgel999/miniz` @ `77d0dce8627735138c51770d1799a1ef48f2117d` (v3.1.2)
- **Oracle:** vendored pristine in `upstream/`, per-file SHA-256 pinned in `scripts/oracle_hashes.txt`
- **License:** MIT (same as upstream)
- **ABI:** 115 exported symbols, identical to upstream

## TL;DR

Measured vs stock upstream `-O2` (clang 23.1.2, Intel i7-14700F, WSL2):

| workload | speedup |
|---|---|
| **Compression** (16-file regime matrix × levels 1/6/9) | **+21.1%** geomean (1.05–1.34× per file) |
| Decompression | +1.7% (parity) |
| **crc32** (isolated) | **4.0×** |
| **adler32** (isolated) | **3.8×** |
| Match scan, ≥32-byte mismatches (isolated) | 4.2–15.3× |
| **Downstream consumer** (2 MiB text, zlib API) | **compress 1.32×**, decompress 1.04× |

No PGO, no AVX2 requirement, no source-API change.

## The exactness contract (what "drop-in" means here)

miniz is a **codec-pair**, so "exact" has three parts, all enforced:

| observable | exact tier |
|---|---|
| deflate byte stream (levels 0–10 × default/filtered/huffman-only/rle/fixed × raw/zlib) | byte-identical to upstream |
| inflate output | bit-identical |
| `mz_adler32` / `mz_crc32` | identical 32-bit values |

Only *mechanics* changed — how a match length is measured and how a copy is
performed. Encoder **choices** (parse, match, Huffman selection) are untouched,
because changing them changes the bytes.

One subtlety drove the design: upstream's 16-bit unaligned match comparator is
byte-identical to the strict-scalar path for **every level except level 1**,
whose separate `tdefl_compress_fast` parser emits different bytes. This fork
therefore enables the fast comparator but forces level 1 onto the normal parser
(`MINIZ_EXACT_LEVEL1`), keeping the entire stream exact.

## What changed

Only `src/` (the candidate) is modified; `upstream/` is never touched. No public
header, struct, or symbol changes.

1. **16-bit unaligned deflate probe filter** (`miniz_tdef.c`) — the upstream
   word-at-a-time filter, adopted for the exact tier with level 1 guarded.
2. **SSE2 match-length scan** (`miniz_simd.h`) — 16-byte `pcmpeqb` /
   `pmovmskb` / `ctz` replacing the byte loop in `tdefl_find_match`.
3. **SSSE3/SSE4.1 adler32** — `psadbw` + `pmaddubsw`, exact wrapping arithmetic.
4. **slicing-by-8 crc32** — portable, exact, 8 KiB of tables.
5. **SSE2 inflate copy** — an out-of-line 16-byte copy for non-overlapping
   matches; the hot overlapping scalar loop is deliberately left alone.

New internal-only files: `src/miniz_simd.h`, `src/miniz_opt.h`. Their helpers
have internal linkage, so the exported ABI is exactly upstream.

## Results

### Compression, by workload (geomean over levels 1/6/9)

| workload | speedup |
|---|---|
| random 1 MiB | 1.05× |
| mixed 64 KiB / 1 MiB | 1.08× / 1.06× |
| runs 64 KiB | 1.12× |
| source 64 KiB / 1 MiB | 1.15× / 1.12× |
| text 64 KiB / 1 MiB | 1.22× / 1.28× |
| zeros / repeat 64 KiB | 1.27× / 1.28× |
| kernel `lib_string.c` / `kconfig_menu.c` | 1.34× |
| upstream `ChangeLog.md` | 1.30× |

The gain is largest on text-like and structured data (longer matches); it is
smallest on incompressible data, where there is nothing to match.

### Downstream consumer

A real program using the zlib-style API (`mz_compress2` / `mz_uncompress`) on
2 MiB of structured text, linked against the **prebuilt library**:

```
consumer,compress,6,   1.3220x   (63.2 ms -> 47.8 ms)
consumer,decompress,6, 1.0351x
```

The consumer number is the honest bound for "every consumer gets faster".

### Isolated kernels

```
adler32,64K   3.783x
crc32,64K     3.994x
match_scan ≥32-byte mismatches   4.2-15.3x
match_scan <16-byte mismatches   0.67-0.99x   (weak regime, reported)
```

Short matches are the one weak regime: SIMD setup costs more than a few byte
compares. In real deflate the evalue prefix filter rejects most candidates before
the scan, so the end-to-end result is still a solid win.

## Compatibility and usage

Requires **x86-64-v2** (SSE4.2/SSSE3, Nehalem 2008+) for the candidate build, the
same distribution baseline the sibling stb forks use. `MINIZ_NO_SIMD` gives a
portable scalar build; `MINIZ_FORCE_BASE` omits AVX2; AVX2 is runtime-dispatched
via self-contained CPUID/XGETBV but is neutral here and kept only for testing.

```c
#include "miniz.h"        /* declarations only */
/* ... mz_compress2(), mz_uncompress(), tdefl_*, tinfl_*, mz_zip_* ... */
```

Link the bundled `libminiz-opt.a`. Header-only consumers get the baseline
scalar/upstream build; only the linked library carries the SIMD gain.

## Rejected experiments (do not retry blindly)

- **Held-out PGO** — regressed inflate to **0.74×** for no compression gain.
  The giant `tinfl_decompress` coroutine is layout-sensitive. Off by default.
- **Upstream 8-byte unaligned inflate copy** — perturbed the overlapping scalar
  copy loop, making `zeros`/`repeat` ~2× slower with identical streams.
- **Compiler/ISA flags alone** — `-O3`, `-march=v2/v3/native`, `-mtune`,
  `-funroll-loops` are all ≈1.00×; the scalar codec is already tight.
- **AVX2 match scan** — neutral vs the inlined SSE2 scan.

See `docs/REJECTED.md`, `docs/MEASUREMENT.md`, and `docs/CONFIG.md`.

## Reproducing

```sh
source scripts/env.sh          # hermetic clang 23.1.2 (or use system CC)
scripts/fetch_corpus.sh        # optional real corpus (Linux kernel subset)
make verify                    # differential + dispatch + ABI + oracle hash
make bench-vs-upstream         # -> results/summary.csv
make kernels                   # -> results/kernels.csv
make consumer                  # -> results/consumer.csv
make sanitize nonvacuous portable asm-audit
```

The oracle is the untouched upstream tree; `make oracle-integrity` re-checks its
hashes. All numbers in this note are reproducible from committed scripts.
